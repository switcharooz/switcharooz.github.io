switcharooz

a minimal nostr identity hub hosted on github pages

what is this?

this repository serves as a lightweight, self-hosted identity layer for the nostr protocol. it hosts the .well-known/nostr.json file required for nip-05 identifier verification, mapping a human-readable name to a public key.

verification

nip-05 clients can verify the identifier spherum@switcharooz.github.io by fetching:

https://switcharooz.github.io/.well-known/nostr.json
