# switcharooz

> a minimal nostr identity hub hosted on github pages

## what is this?

this repository serves as a lightweight, self-hosted identity layer for the nostr protocol. it hosts the `.well-known/nostr.json` file required for [nip-05](https://github.com/nostr-protocol/nips/blob/master/05.md) identifier verification, mapping a human-readable name to a public key.

## structure

```
.
├── README.md
└── .well-known/
    └── nostr.json
```

## nostr.json

```json
{
  "names": {
    "spherum": "48ca053916454f5d6171da28b677ce9a4922e672fb0e5707d1bb69bf1d4b2dff"
  }
}
```

## verification

nip-05 clients can verify the identifier `spherum@switcharooz.github.io` by fetching:

```
https://switcharooz.github.io/.well-known/nostr.json
```
